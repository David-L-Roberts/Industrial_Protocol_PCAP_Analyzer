# 03: DNP3 Solicited, Unsolicited, Direct-No-Ack & Edge-Case Trace Spans

**What to build:** Extend the pure DNP3 decoder to parse all Application Control header flags (`FIR`, `FIN`, `CON`, `UNS`, `SEQ`) and emit complete **Trace Spans** with low-cardinality operation names, rich DNP3 attributes, and timeline events for solicited request/response exchanges, outstation-initiated Unsolicited Responses (`FC 0x82`), Direct Operate No-Ack commands (`FC 0x06`), malformed frames, and unpaired orphan `FC 0x81` responses—while stamping `(TraceId, SpanId)` onto all correlated **RED Metrics**, **Captured Command Events**, and **Extracted Data Points** without changing the existing `IDnp3ObjectGroupHandler` interface.

Non-RED protocol activity (Unsolicited Responses, Direct Operate No-Ack, and Orphan Responses) gains full visibility in `trace_spans` while leaving `red_transactions` strictly focused on request/response RED KPIs. When tracing is disabled (`StoreTraceSpans == false`), zero spans are emitted and all `trace_id`/`span_id` fields remain `null`.

**Blocked by:** 01: End-to-End Trace Span Persistence Spine, Configuration & Opt-Out

**Status:** resolved

- [x] The DNP3 decoder parses all Application Control header bits (`FIR`, `FIN`, `CON`, `UNS`, `SEQ`) and populates DNP3 span attributes (`dnp3.src`, `dnp3.dst`, `dnp3.app_seq`, `dnp3.fir`, `dnp3.fin`, `dnp3.con`, `dnp3.uns`, `dnp3.iin1`, `dnp3.iin2`, `dnp3.object_groups`, `dnp3.target_address` when CROB present, IPs/ports, frame byte lengths, `tags.matched_count`, `tags.changed_count`).
- [x] Solicited DNP3 requests (`FC 0x01`, `0x02`, `0x03`, `0x04`, `0x05`, `0x0D`, `0x0E`, `0x14`, `0x15`, `0x17`, etc.) pre-allocate deterministic `(TraceId, SpanId)` values, attach `PendingSpanContext` with low-cardinality `OperationName` (e.g., `DNP3 FC01 Read`, `DNP3 FC03 Select`) and `ServiceName = ServerEndpoint`, stamp `(TraceId, SpanId)` onto any request-side `ExtractedDataPointRecord` and `CapturedCommandEventRecord` rows, and emit a `RequestResponse` span (or `Timeout`/`TimeoutAtEof` error span) upon matching `FC 0x81` response or Virtual Clock expiration.
- [x] Matched `FC 0x81` responses preserve the initiating request's `OperationName`, map **IIN** error bits to `StatusCode = Error` + `StatusMessage` + `ProtocolException` event, append `ResponseReceived` and up to 10 `TagValueChanged` events (with `tags.changes_truncated = true` when exceeded), and stamp `(TraceId, SpanId)` onto all response-side `ExtractedDataPointRecord` and `CapturedCommandEventRecord` rows without altering the `IDnp3ObjectGroupHandler` signature.
- [x] DNP3 Unsolicited Responses (`FC 0x82`, `ServerToClient`) emit a zero-duration root `Unsolicited` span (`SpanKind = Consumer`, `ServiceName = ClientEndpoint`, `OperationName = "DNP3 FC130 UnsolicitedResponse"`, `StatusCode = Error` if IIN error else `Ok`), stamp `(TraceId, SpanId)` onto extracted `ExtractedDataPointRecord` rows, and do not emit a `ProtocolTransactionRecord`.
- [x] DNP3 Direct Operate No-Ack requests (`FC 0x06`, `ClientToServer`) emit a zero-duration root `DirectNoAck` span (`SpanKind = Producer`, `ServiceName = ServerEndpoint`, `OperationName = "DNP3 FC06 DirectOperateNoAck"`, `StatusCode = Ok`, `CommandIssued` event), stamp `(TraceId, SpanId)` onto extracted `CapturedCommandEventRecord` and `ExtractedDataPointRecord` rows, and do not register a pending response timeout.
- [x] Unpaired `FC 0x81` responses (`TryCompleteResponse == false`) emit a zero-duration `OrphanResponse` span (`OperationName = "DNP3 FC129 Response"`, `ServiceName = ClientEndpoint`, `protocol.unpaired = true`, `StatusCode = Error` if IIN error else `Unset` with `StatusMessage = "ORPHAN_RESPONSE"`) without emitting a `ProtocolTransactionRecord`.
- [x] Malformed DNP3 frames stamp `(TraceId, SpanId)` onto the malformed `ProtocolTransactionRecord` and emit a zero-duration `Malformed` error span (`OperationName = "DNP3 MalformedFrame"`).
- [x] When `StoreTraceSpans` is `false`, zero `TraceSpanRecord` rows are emitted and `TraceId`/`SpanId` remain `null` across all DNP3 outputs.
- [x] Unit tests verify all DNP3 span classifications, IIN error events, tag-change event capping, handler non-breaking stamping, and opt-out mode without external binaries; live DNP3 PCAP integration tests confirm `trace_spans` persistence and cross-table correlation in TimescaleDB.
